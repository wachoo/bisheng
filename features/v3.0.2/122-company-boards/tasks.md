## 首次本地部署记录

在 Windows 的独立 Compose 项目 `bisheng-dev` 使用原本地组织和账号。管理员从登录页进入两个看板，三个领导视图、运行监控、反馈与台账可访问。普通用户从 Web 工作台边栏点“监控看板”即可进入。该角色只获得监控菜单授权，直接请求领导汇总、台账接口均被服务端拒绝。原 `/dashboard` 可打开。

管理员从网页新建年度目标 7，修改为 8 后再次进入领导页，目标读数为 8。知识集目标从计划内的知识集清单计算，网页新增数值目标仅提供数字员工与场景。已清理该验收记录的两次修订。当前开发库有 43 项目录资产；真实业务台账和运行事实等待实际填报及调用产生。

后端初版看板测试集 20 项通过，覆盖同租户与跨租户读取、公司级角色授予、台账版本、真实助手处理器、握手复用、纯等待、失败和跨执行文件归集、反馈截止日与处置。运行链路用受控模型及内存数据库验证。数据库迁移到 `f122_board_members`。
