# F122 公司 Web 看板初版

首期用户通过本地毕昇 Web 使用公司领导看板与运行监控。原型基线为飞书《公司 AI 产品看板设计方案》修订 251，统计口径以 2026-11-25 评审的《Web 看板落地方案》为准。

| 验收项 | 使用结果 |
|---|---|
| AC-01 入口 | 公司领导可访问 /leadboard 的战略进展、业务赋能和应用活力。获监控授权的员工可访问 /monitorboard。系统管理员可验证全部视图。原 /dashboard、编辑和分享继续使用原产品路由。 |
| AC-02 权限 | 服务端基于已登录用户及当前租户判断访问。监控汇总、台账写入、反馈处置分开授权。访问汇总的普通员工无法读取未授权的操作明细。 |
| AC-03 建设台账 | 两类获授权的管理员可填报年度目标、专题、场景、资产首发计划和知识集验证，并更正记录。页面按统计截止日从明细汇总。场景首次实际投产、资产首次正式上线、知识验证分别判断。 |
| AC-04 运行与交付 | 已接入的正式 Web 助手按真实任务终态计数。实际 Skill 调用去重，工具失败独立于父任务。成功和失败任务均计有效时长，扣除纯工具等待。普通输出文件逐件计，项目版本按一版一件。标明采集范围和未知值。 |
| AC-05 反馈 | 有权人员可查看已观测成功任务的差评问题并填写处置措施。管理员办结不改用户评价。普通监控读者只见数量。 |
| AC-06 本机运行 | 使用本地已有数据库、账号和组织关系，从正常登录页访问两个入口，验证既有页面仍可打开。用隔离样本验证采集，不将测试用量计入业务。 |
